## 1. การติดตั้ง GitHub Desktop บน Windows

1. ดาวน์โหลดไฟล์ติดตั้งจาก [desktop.github.com](https://desktop.github.com)
2. เปิดไฟล์ `GitHubDesktopSetup.exe` ที่ดาวน์โหลดมา
3. ระบบจะทำการติดตั้งโปรแกรมโดยอัตโนมัติ และเปิดหน้าต่างโปรแกรมขึ้นมาเมื่อติดตั้งเสร็จสิ้น

---

## 2. การติดตั้ง GitHub Desktop บน macOS

1. ดาวน์โหลดไฟล์ติดตั้งจาก [desktop.github.com](https://desktop.github.com)
2. เปิดไฟล์ `.zip` ที่ได้มาเพื่อแตกไฟล์
3. ลากไอคอน **GitHub Desktop** ไปไว้ในโฟลเดอร์ **Applications**
4. เปิดโปรแกรมจากโฟลเดอร์ Applications

---

## 3. การเชื่อมต่อบัญชี GitHub (Sign In)

1. เมื่อเปิดโปรแกรมครั้งแรก ให้คลิกปุ่ม **Sign in to GitHub.com**
2. โปรแกรมจะพาคุณไปยังหน้าเว็บเบราว์เซอร์ เพื่อยืนยันการเข้าใช้งาน
3. กดปุ่มสีเขียว **Authorize desktop**
4. ระบบจะสลับกลับมาที่โปรแกรม GitHub Desktop
5. กำหนดชื่อผู้ใช้ (Name) และอีเมล (Email) ที่ต้องการให้แสดงในประวัติการแก้ไขไฟล์ (Git Commit)
6. กด **Finish** เพื่อเสร็จสิ้นขั้นตอนการตั้งค่า
