## 1. Branch คืออะไร?

Branch (สาขา) คือการจำลองพื้นที่ทำงานแยกออกมาจากโค้ดหลัก (Main Branch) เพื่อให้คุณสามารถทดลองหรือพัฒนาฟีเจอร์ใหม่ๆ ได้อย่างปลอดภัย โดยไม่เสี่ยงทำโค้ดหลักเสียหาย

---

## 2. การสร้างและสลับ Branch ใน GitHub Desktop

1. เปิดโปรแกรม **GitHub Desktop**
2. คลิกที่แถบ **Current Branch** ด้านบนสุด
3. กดปุ่ม **New Branch**
4. ตั้งชื่อ Branch ใหม่ (แนะนำให้ใช้ภาษาอังกฤษสั้นๆ เช่น `feature/add-login` หรือ `fix/readme-typo`)
5. กดปุ่ม **Create Branch**

---

## 3. การแก้ไขงานและ Push บน Branch

1. เปิดแก้ไขไฟล์ใน VS Code ตามปกติ
2. เมื่อแก้ไขเสร็จ ให้สลับกลับมาที่ GitHub Desktop
3. พิมพ์ Summary อธิบายงาน แล้วกด **Commit to [ชื่อ branch ของคุณ]**
4. กดปุ่ม **Publish branch** (หรือ Push origin) เพื่อส่ง Branch นี้ขึ้นสู่ GitHub

---

## 4. การสร้าง Pull Request (PR) บน GitHub

เมื่อพัฒนาฟีเจอร์เสร็จแล้ว และต้องการนำโค้ดไปรวมกับ Branch หลัก (main):

1. ในโปรแกรม GitHub Desktop จะมีปุ่มขึ้นว่า **Create Pull Request** ให้คลิกปุ่มนั้น (หรือเข้าสร้างผ่านเว็บ GitHub)
2. ระบบจะพาไปยังหน้าเว็บ GitHub
3. พิมพ์หัวข้อและรายละเอียดว่าคุณได้แก้ไขหรือเพิ่มฟีเจอร์อะไรลงไปบ้าง
4. กดปุ่มสีเขียว **Create Pull Request**

---

## 5. การ Merge รวมโค้ดเข้าสู่ Main

1. เมื่อเพื่อนร่วมทีมหรือหัวหน้างานตรวจสอบโค้ด (Code Review) เรียบร้อยแล้ว
2. กดปุ่มสีเขียว **Merge pull request** บนหน้าเว็บ GitHub
3. กด **Confirm merge** เพื่อรวมโค้ดเข้าสู่ Branch main
4. เมื่อเสร็จแล้ว สามารถกด **Delete branch** เพื่อลบสาขาชั่วคราวทิ้งได้เลย
