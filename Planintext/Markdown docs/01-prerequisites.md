## 1. การสมัครบัญชี GitHub

GitHub เป็นคลาวด์เซิร์ฟเวอร์หลักที่ใช้จัดเก็บไฟล์และประวัติโครงการของคุณ คุณจำเป็นต้องมีบัญชีเพื่อเชื่อมต่อกับโปรแกรม GitHub Desktop

1. เข้าไปที่เว็บไซต์ [github.com](https://github.com)
2. คลิกปุ่ม **Sign up** ที่มุมขวาบน
3. กรอกข้อมูลเพื่อสร้างบัญชี:
   * **Email:** ใส่อีเมลที่คุณใช้งานจริง
   * **Password:** ตั้งรหัสผ่านที่ปลอดภัย
   * **Username:** ตั้งชื่อผู้ใช้ (แนะนำให้ใช้ภาษาอังกฤษและตัวเลข)
4. ยืนยันตัวตนผ่านอีเมลที่คุณได้รับจากระบบ

---

## 2. การติดตั้งโปรแกรม Visual Studio Code (VS Code)

VS Code เป็นเครื่องมือสำหรับแก้ไขไฟล์โค้ดและไฟล์ Markdown (`.md`) ที่นิยมและใช้งานง่ายที่สุด

1. ดาวน์โหลดโปรแกรมได้ที่ [code.visualstudio.com](https://code.visualstudio.com)
2. เปิดไฟล์ติดตั้งตามระบบปฏิบัติการของคุณ (Windows / macOS)
3. **คำแนะนำพิเศษสำหรับ Windows:** ในขั้นตอนการติดตั้ง ให้ติ๊กเลือกช่อง:
   * `Add "Open with Code" action to Windows Explorer context menu`
   * `Add to PATH`
4. กด **Next** และ **Install** จนเสร็จสิ้น

---

## 3. การติดตั้งโปรแกรม GitHub Desktop

GitHub Desktop เป็นโปรแกรมกราฟิก (GUI) ที่ช่วยให้คุณใช้งาน Git ได้โดยไม่ต้องพิมพ์คำสั่งใน Command Line

1. ดาวน์โหลดโปรแกรมได้ที่ [desktop.github.com](https://desktop.github.com)
2. ติดตั้งโปรแกรมลงในเครื่อง
3. เมื่อเปิดโปรแกรมครั้งแรก ระบบจะให้ Sign In เข้าสู่ระบบ ให้เลือก **Sign in to GitHub.com**
4. โปรแกรมจะเปิดเว็บเบราว์เซอร์ขึ้นมา ให้กดอนุญาต (Authorize) เพื่อเชื่อมต่อบัญชี
