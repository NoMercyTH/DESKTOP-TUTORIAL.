## 1. GitHub Pages คืออะไร?

GitHub Pages เป็นบริการฟรีจาก GitHub ที่ช่วยแปลงไฟล์เอกสาร Markdown (`.md`) ใน Repository ให้กลายเป็นหน้าเว็บไซต์ที่สวยงาม เข้าถึงได้ผ่าน URL สาธารณะ เพื่อให้ผู้อื่นเปิดอ่านคู่มือได้สะดวกโดยไม่ต้องดาวน์โหลดไฟล์

---

## 2. ขั้นตอนการเปิดใช้งาน GitHub Pages

1. ไปที่หน้าหลักของ Repository บนเว็บ GitHub
2. คลิกที่แถบเมนู **Settings** (รูปฟันเฟือง) ที่ด้านบน
3. ที่เมนูด้านซ้ายมือ เลือกหัวข้อ **Pages** (ในหมวด Code and automation)
4. ในส่วน **Build and deployment**:
   * **Source:** เลือก `Deploy from a branch`
   * **Branch:** เลือก branch `main`
   * **Folder:** เลือกโฟลเดอร์ที่เป็นตำแหน่งเก็บเอกสารของคุณ (เช่น `/docs` หรือเลือก `/ (root)` ขึ้นอยู่กับโครงสร้าง)
5. กดปุ่ม **Save**

---

## 3. การเข้าถึงหน้าเว็บไซต์คู่มือ

1. หลังจากกด Save ให้รอระบบประมวลผลประมาณ 1–3 นาที
2. ลองรีเฟรชหน้าต่าง **Settings** ➔ **Pages**
3. ด้านบนสุดจะปรากฏกรอบสีเขียวพร้อมลิงก์เว็บไซต์ เช่น:
   `https://[username].github.io/[repository-name]/`
4. คุณสามารถคัดลอกลิงก์นี้ไปแชร์ให้ผู้เรียนหรือคนในทีมเปิดอ่านคู่มือได้ทันที
