## 1. การ Clone Repository ลงคอมพิวเตอร์

การ Clone คือการดาวน์โหลดคลังเก็บไฟล์จาก GitHub บนเว็บ ลงมาเก็บไว้บนเครื่องคอมพิวเตอร์ของคุณ

1. เปิดโปรแกรม **GitHub Desktop**
2. ไปที่เมนู `File` ➔ `Clone Repository...`
3. เลือกแท็บ **GitHub.com** เลือกชื่อ Repository ที่ต้องการ แล้วกด **Clone**

---

## 2. การแก้ไขไฟล์ในโครงการ

1. ในโปรแกรม GitHub Desktop ให้กดปุ่ม **Open in Visual Studio Code**
2. ทำการเพิ่ม แก้ไข หรือลบเนื้อหาในไฟล์ที่ต้องการ แล้วกด `Ctrl + S` เพื่อบันทึกไฟล์

---

## 3. การ Commit (บันทึกจุดเปลี่ยนแปลง)

1. สลับกลับมาที่โปรแกรม **GitHub Desktop**
2. แถบด้านซ้ายมือจะแสดงรายการไฟล์ที่มีการแก้ไข (Changes)
3. ที่มุมล่างซ้าย ช่อง **Summary** ให้เขียนข้อความสรุปสั้นๆ ว่าแก้ไขอะไรไปบ้าง เช่น:
   * `Add basic workflow lesson`
   * `Fix typo in README`
4. กดปุ่มสีฟ้า **Commit to main**

---

## 4. การ Push (ส่งไฟล์ขึ้น GitHub)

การ Commit เป็นเพียงการบันทึกไว้ในเครื่องคอมพิวเตอร์เท่านั้น หากต้องการให้อัปโหลดขึ้นเว็บ GitHub:

1. คลิกปุ่ม **Push origin** ที่แถบด้านบนสุดของ GitHub Desktop
2. รอระบบประมวลผลการอัปโหลดสักครู่

---

## 5. การ Pull (ดึงไฟล์ล่าสุดจาก GitHub)

หากมีการแก้ไขไฟล์บนเว็บ GitHub หรือมีคนอื่นในทีมส่งโค้ดใหม่ขึ้นไป:

1. กดปุ่ม **Fetch origin** ด้านบนเพื่อตรวจสอบการอัปเดต
2. หากมีข้อมูลใหม่ ปุ่มจะเปลี่ยนเป็น **Pull origin** ให้คลิกเพื่อดึงไฟล์ล่าสุดลงมาที่เครื่อง
