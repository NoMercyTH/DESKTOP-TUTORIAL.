## ⚙️ ข้อกำหนดและสิ่งที่ต้องเตรียมก่อนเริ่ม (Prerequisites)

ก่อนเริ่มทำตามบทเรียน กรุณาตรวจสอบความพร้อมของซอฟต์แวร์และอุปกรณ์ดังต่อไปนี้:

### 1. ความรู้พื้นฐานที่ควรมี
* การจัดการไฟล์และโฟลเดอร์บน Windows หรือ macOS
* ความเข้าใจเบื้องต้นเกี่ยวกับการใช้งานอินเทอร์เน็ตและ Web Browser

### 2. เครื่องมือและซอฟต์แวร์ที่ต้องเตรียม
| เครื่องมือ | รายละเอียด | ลิงก์ดาวน์โหลด / สมัคร |
|---|---|---|
| **GitHub Account** | บัญชีสำหรับจัดเก็บคลาวด์ Repository | [github.com](https://github.com) |
| **GitHub Desktop** | โปรแกรม GUI จัดการ Git แบบง่าย | [desktop.github.com](https://desktop.github.com) |
| **Code Editor** | แนะนำ Visual Studio Code | [code.visualstudio.com](https://code.visualstudio.com) |

*(อ่านรายละเอียดการเตรียมตัวเพิ่มเติมได้ในเอกสาร `docs/01-prerequisites.md`)*

## 📥 ขั้นตอนการติดตั้งและตั้งค่า

1. **ติดตั้ง GitHub Desktop:** ดาวน์โหลดและติดตั้งตามระบบปฏิบัติการของคุณ (Windows หรือ Mac)
2. **เชื่อมต่อบัญชี (Sign In):**
   * เปิด GitHub Desktop ➔ ไปที่ `File` → `Options` (Windows) หรือ `GitHub Desktop` → `Settings` (Mac)
   * ไปที่แท็บ **Accounts** เลือก **Sign in to GitHub.com**
   * ล็อกอินผ่านเว็บเบราว์เซอร์ให้เรียบร้อย

## 🛠️ ปัญหาที่พบบ่อยและวิธีแก้ไข (Troubleshooting)

### ❌ 1. เข้าสู่ระบบ (Login / Authentication) ไม่ผ่าน
* **สาเหตุ:** รหัสผ่านผิด หรือ Token การยืนยันตัวตนหมดอายุ
* **วิธีแก้ไข:** 
  1. เปิดโปรแกรม GitHub Desktop ไปที่ `File` > `Options` > `Accounts`
  2. กด **Sign Out** แล้วกด **Sign In** ใหม่อีกครั้งผ่าน Web Browser

### ❌ 2. ส่งไฟล์ไม่ผ่าน (Push Rejected / Conflicts)
* **สาเหตุ:** บน GitHub (Remote) มีไฟล์อัปเดตใหม่กว่าเครื่องของคุณ (Local) หรือมีการแก้ไขไฟล์ทับซ้อนกัน
* **วิธีแก้ไข:** 
  1. กดปุ่ม **Fetch origin** และ **Pull origin** เพื่อดึงไฟล์ล่าสุดลงมาที่เครื่องก่อนเสมอ
  2. หากพบปัญหา **Merge Conflict** ให้เปิดไฟล์ด้วย VS Code เลือกจุดที่ต้องการเก็บไว้ บันทึกไฟล์ แล้ว Commit/Push อีกครั้ง

*(อ่านคู่มือการแก้ไขปัญหาอย่างละเอียดได้ใน `docs/05-troubleshooting.md`)*

## 🌐 การเปิดใช้งานหน้าเว็บด้วย GitHub Pages (Optional)

คุณสามารถแปลงเอกสารบทเรียนในโฟลเดอร์ `docs/` ให้กลายเป็นหน้าเว็บไซต์อ่านออนไลน์ได้ฟรี:

1. ไปที่ Repository ของคุณบน GitHub (`https://github.com/NoMercyTH/DESKTOP-TUTORIAL.`)
2. คลิกแถบ **Settings** (เมนูด้านบน) ➔ เมนูด้านซ้ายเลือก **Pages**
3. ในส่วน **Build and deployment**:
   * **Source:** เลือก `Deploy from a branch`
   * **Branch:** เลือก `main` และเปลี่ยนโฟลเดอร์จาก `/ (root)` เป็น **`/docs`**
4. กด **Save** แล้วรอประมวลผลประมาณ 1–2 นาที คุณจะได้ URL เว็บไซต์สำหรับเปิดอ่านคู่มือได้ทันที

## 📖 คำศัพท์ที่สำคัญ

| คำศัพท์ | ความหมายเข้าใจง่าย |
|---|---|
| **Repository (Repo)** | โฟลเดอร์โครงการที่ใช้เก็บไฟล์และประวัติการแก้ไข |
| **Commit** | การบันทึกจุดเปลี่ยนแปลงของไฟล์ พร้อมเขียนอธิบาย |
| **Push** | การส่ง/อัปโหลดไฟล์จากคอมพิวเตอร์ขึ้นคลาวด์ GitHub |
| **Pull** | การดึง/ดาวน์โหลดไฟล์ล่าสุดจาก GitHub ลงมาที่คอมพิวเตอร์ |
| **Branch** | การแตกสาขาเพื่อแก้ไขโค้ด/ฟีเจอร์ โดยไม่กระทบกับงานหลัก |
